# Capsid Trademark Policy

“Capsid” and the Capsid logo identify the official Capsid project.

## General rule

The software license grants rights to the code only. It does not grant
permission to use the Capsid name or logo. A fork, modified build, or
re-packaged distribution that changes the source must use a different
product name.

## Permitted use

You may use the Capsid name without separate permission to:

- refer to the unmodified official project;
- state that your software is “compatible with Capsid” or “integrates with
  Capsid” when the statement is accurate;
- describe APIs, protocols or configuration files from the official project;
- report bugs or contribute to the official repository.

## Prohibited use

Do not use Capsid in a way that suggests official endorsement, including:

- “Capsid Pro”, “Capsid Cloud”, “Official Capsid”, “Capsid Enterprise”;
- logos or branding that imitate the official identity;
- domains or package names that could be confused with the official project;
- certification marks such as “Capsid Certified Runtime” without passing the
  official certification process (see docs/certification.md).

Forks and derived products must choose a distinct name and state clearly that
they are not the official Capsid project.
