# Capsid v0.2.2

Capsid v0.2.2 adds the first deployed compile-time bytecode rewrite
pipeline and the profiling infrastructure used to select it. The public C ABI
remains v7 and FetchRPC remains v3.

## Highlights

- Rewrite trusted QuickJS bytecode at compile time while preserving ordinary
  BC26 output, deterministic serialization, attestation, and runtime
  compatibility.
- Deploy the measured `kPassAll` reductions and mixed-number multiplication
  fast path. The retained Kraken/Octane portfolio measured a +2.91%
  equal-weight gain with a paired 95% confidence interval of
  [+0.84%, +5.02%].
- Add fail-closed bytecode parsing, CFG and stack validation, pc2line remapping,
  source/bytecode differential coverage, and a seeded sanitizer fuzz target.
- Add exact-site profiling and analyze-only CFG+SSA region census tooling for
  future multi-instruction fusion work.
- Keep field IC, BC27 fusion, and ext34 disabled or removed after their final
  product gates failed; default builds pay no active dispatch or sidecar cost
  for those experiments.
- Consolidate QuickJS optimization guidance and publish only the latest
  maintained performance evidence.

## Compatibility

- No public C ABI changes; the ABI remains v7.
- No FetchRPC changes; the protocol remains v3.
- Trusted bytecode should be recompiled with the v0.2.2 compiler because the
  build compatibility identity includes the runtime version and rewriter
  configuration.

## Install

Install the latest stable release:

```sh
curl -fsSL https://github.com/ErosZy/capsid/releases/latest/download/install.sh | bash
```

Install this exact release:

```sh
curl -fsSL https://github.com/ErosZy/capsid/releases/download/v0.2.2/install.sh | bash -s -- v0.2.2
```

Every archive is accompanied by a SHA-256 checksum. The installer verifies the
checksum before extracting files.
