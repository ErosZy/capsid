# Capsid v0.2.2

Capsid v0.2.2 is a maintenance release that restores the proven v0.2.1
runtime path and removes the unreleased txiki.js/QuickJS-ng optimization
experiments. The public C ABI remains v7 and FetchRPC remains v3.

## Highlights

- Remove the experimental bytecode rewriting and opcode-profiling pipeline.
- Remove the experimental QuickJS overlay fast paths and their build options.
- Remove the associated benchmark fixtures, generated evidence, tests, and
  design documentation.
- Keep the pinned txiki.js/QuickJS-ng runtime and the existing security,
  compatibility, and packaging behavior unchanged.
- Improve Windows CI compiler-error annotations.

## Compatibility

- No public C ABI changes; the ABI remains v7.
- No FetchRPC changes; the protocol remains v3.
- Trusted bytecode should be recompiled for v0.2.2 because the build
  compatibility identity includes the runtime version.

## Install

Install the latest stable release:

```sh
curl -fsSL https://github.com/ErosZy/capsid/releases/latest/download/install.sh | bash
```

Install this exact release:

```sh
curl -fsSL https://github.com/ErosZy/capsid/releases/download/v0.2.2/install.sh | bash -s -- v0.2.2
```

Every archive is accompanied by a SHA-256 checksum. The installer verifies the
checksum before extracting files.
