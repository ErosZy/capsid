# Capsid v0.2.1

Capsid v0.2.1 is a focused patch release for cookie handling in outbound HTTP fetches. The runtime ABI remains at v7 and FetchRPC remains at v3.

## Fixes

- Backport libwebsockets commit `da0c875c84e7ee824e83f95c40b302598b84ee98` so `Secure` and `HttpOnly` attributes no longer overwrite a cookie's stored name and value. This resolves the failure reported in [txiki.js #1064](https://github.com/saghul/txiki.js/issues/1064) and preserves `Domain` cookie semantics.
- Add a regression test against the actual libwebsockets cookie jar built into Capsid, covering exact name/value persistence, the `Secure` flag, `HttpOnly`, and host-only versus domain-cookie behavior.
- Extend the txiki.js overlay integrity and identity gates to include the new backport.

## Compatibility

- No public C ABI changes; the ABI remains v7.
- No FetchRPC changes; the protocol remains v3.
- Existing v0.2.0 applications do not require migration.

## Install

Install the latest stable release:

```sh
curl -fsSL https://github.com/ErosZy/capsid/releases/latest/download/install.sh | bash
```

Install this exact release:

```sh
curl -fsSL https://github.com/ErosZy/capsid/releases/download/v0.2.1/install.sh | bash -s -- v0.2.1
```

Every archive is accompanied by a SHA-256 checksum. The installer verifies the checksum before extracting files.
