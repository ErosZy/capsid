# Capsid v0.3.0-beta.3

Experimental `0.3.0-beta` release (`v0.3.0-beta.3`; runtime version string `0.3.0`; public C ABI v7), not a stable-production recommendation. Set as the GitHub `Latest` release for convenient installation while `v0.2.2` remains the latest stable `0.2.x` release.

## Highlights

- Native five-platform archive matrix: `linux-musl-x86_64`, `linux-musl-arm64`, `darwin-arm64`, `darwin-x86_64`, and `windows-x86_64` built on separate native CPU runners (fully static musl Linux builds, thin native macOS builds, MSVC static-CRT Windows archive).
- Architecture-aware `install.sh` selecting the exact OS/CPU archive, with legacy `capsid-*-linux-musl.tar.gz` compatibility fallback permitted only on `x86_64`.
- Pinned C/C++, JavaScript, and Python source formatting (`clang-format` 23.1.5, `prettier` 3.8.3, `ruff` 0.17.5) while preserving raw fixtures, encoding locks, generated data, and historical captures.

## Compatibility and Limitations

- Public C ABI remains v7; FetchRPC defaults to v3, with additive v4/WebSocket support available only by explicit negotiation. Keep Host, worker, compiler, and SDK binaries from the same build together and recompile trusted bytecode for the matching compatibility ID.
- Linux strict sandboxing requires the documented kernel/delegation prerequisites for untrusted workloads. Native macOS/Windows and local non-isolated modes are trusted-code development/integration modes, not production isolation.
- App `pidsMax` is schema-recognized but is not effective per-App PID enforcement in this release.
- Five retained raw WPT failure files (Headers basic/errors, two promise-rejection files, and MessagePort initial-disabled behavior) and genuine prerequisite skips remain explicit under `CAPSID-WORKERD-v1.20261010.1-default-v2`. Green compatibility CI does not claim full standards conformance.
- Accepted local performance snapshot `485b29b` remains source-bound to its original measurement session and is not a new measurement of `v0.3.0-beta.3`.

## Installation

Install the current `0.3.0-beta` release (currently set as GitHub `Latest`):

```sh
curl -fsSL https://github.com/ErosZy/capsid/releases/latest/download/install.sh | bash
```

Install `v0.3.0-beta.3` explicitly:

```sh
curl -fsSL https://github.com/ErosZy/capsid/releases/download/v0.3.0-beta.3/install.sh | bash -s -- v0.3.0-beta.3
```

Install the stable `v0.2.2` release explicitly:

```sh
curl -fsSL https://github.com/ErosZy/capsid/releases/download/v0.2.2/install.sh | bash -s -- v0.2.2
```

Windows users should download `capsid-0.3.0-windows-x86_64.zip` and its `.sha256` sidecar from this Release, verify SHA-256, and extract to a new directory.
